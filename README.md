# Netaji Hotel - Admin & Restaurant Management System

Executive Operations & Restaurant Management Dashboard for Netaji Hotel (Katora Talab, Raipur).

## Features
- 📊 **Executive Overview & KPI Dashboard**: Real-time sales, order volume, average order value, pending actions.
- 📦 **Live Orders Management**: Instant order workflow (Pending, Preparing, Out for Delivery, Completed).
- 🍽️ **Menu & Catalog Control**: Stock status, price editing, category management.
- 📋 **Bulk / Corporate Inquiries**: Track banquet, party, and festive bulk order requests.
- 📊 **Excel Sync & Data Export**: Export orders, revenue, and customer records directly to `.xlsx`.
- ⚙️ **Store & System Settings**: Working hours, tax rates, contact channels, delivery radiuses.

## Tech Stack
- Next.js 15 (App Router)
- React 19 & TypeScript
- Lucide React (Icons)
- XLSX (SheetJS)

## Getting Started
```bash
# Install dependencies
npm install

# Run development server (runs on port 3001)
npm run dev
```

Open [http://localhost:3001](http://localhost:3001) in your browser.
